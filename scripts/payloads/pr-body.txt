### What is implemented

**#32 — React + Vite frontend setup**

- Vehicle table: type icons (🚗🏍🚚⚡), make/model combined, aria-labels on buttons

**#44 — Frontend-backend API integration**
- All API paths verified against actual backend controllers

- Backend error messages propagated to UI; never hardcoded

**#48 — Responsive layout and accessibility**
- Full design system in `index.css`: Inter font, design tokens, consistent spacing/shadows
- Responsive navbar with hamburger at 768px
- Skip-to-content link for keyboard navigation
- `focus-visible` outlines on all interactive elements
- `aria-required`, `aria-describedby`, `aria-label`, `aria-busy`, `aria-live`, `role=alert` throughout
- No horizontal overflow at 375px verified
